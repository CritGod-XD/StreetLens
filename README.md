# PathVision Pavement Condition Dashboard — Flask version

Converted from the supplied React/TypeScript/Tailwind project into:

- Python + Flask
- Jinja2 templates
- HTML
- Plain CSS
- Plain JavaScript

## Run

```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
python app.py
```

Then open http://127.0.0.1:5000

Login is a prototype: any values are accepted and the Login button opens the dashboard.

Route details are hidden by default and can be expanded with the toggle.
